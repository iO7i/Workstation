# Examples only

All files here describe a disposable project `example`. No real vendor quota, live agent
session or actual production resource is asserted. Endpoints use reserved example.org.
The Work Item example has no workspace; register a disposable Git worktree and explicitly
set workspace_id in a new work item before using checkpoint/handoff commands.

Record inputs are proposals until the explicit CLI digest acknowledgement. A typed
record can store project state but cannot install anything or bypass an application
repair gate. The generated synthetic-demo files below are SQL/reference output, not
output from a compiled Workstation application. Read their provenance fields.
